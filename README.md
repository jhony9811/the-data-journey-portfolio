# The Data Journey — Website

This folder contains the static website for **The Data Journey**.

## Publish it with GitHub Pages

1. Upload all files and folders to the root of your repository.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the **main** branch and the **/(root)** folder.
6. Click **Save**.
7. Wait one or two minutes and open the GitHub Pages URL displayed there.

## Files

- `index.html` — page structure
- `styles.css` — visual design
- `script.js` — mobile menu
- `assets/images/hero-city.png` — hero background

Replace `your-email@example.com` in `index.html` with your real contact email.
